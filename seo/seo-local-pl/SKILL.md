# Local SEO — Polska

## Cel
Przygotuj oparty na dowodach audyt lokalnego SEO dla wskazanej polskiej firmy. Nie zakładaj, że dostęp do Google Search Console, Google Business Profile lub WordPressa jest dostępny.

## Dane wejściowe
Poproś o adres strony, miasto, rodzaj usług i najważniejsze zapytania, jeśli nie zostały podane. Dla porównań konkurencji korzystaj wyłącznie z rzeczywiście zweryfikowanych stron.

## Procedura
1. Sprawdź publiczne adresy URL, statusy HTTP, przekierowania, robots.txt, mapy witryny i tagi canonical, jeśli narzędzia pozwalają na odczyt. Odróżnij brak dostępu od błędu witryny.
2. Przeanalizuj tytuły, meta descriptions, H1, strukturę nagłówków, treść usług, linki wewnętrzne oraz dostępność mobilną. Nie twierdź, że zmierzono Core Web Vitals bez danych pomiarowych.
3. Zweryfikuj dane NAP (nazwa, adres, telefon) w dostępnych oficjalnych źródłach. Nie wymyślaj adresu ani godzin.
4. Oceń dane schema.org LocalBusiness i właściwy podtyp, zgodność z widoczną treścią, poprawność pól i duplikaty. Nie obiecuj rich results.
5. Przygotuj mapę fraz z intencją lokalną (usługa + miasto), rozróżniając dane rzeczywiste od hipotez. Bez GSC nie podawaj wymyślonych kliknięć, pozycji i CTR.
6. Sprawdź indeksowalność najważniejszych podstron. Status w Google potwierdzaj wyłącznie z odpowiednich danych, nie na podstawie samego istnienia URL.
7. Zaproponuj zmiany w kolejności: krytyczne techniczne, lokalne sygnały zaufania, treści i linkowanie, monitoring.

## Wynik
Raport po polsku: URL / problem / dowód / wpływ / priorytet / proponowana poprawka / sposób weryfikacji. Oddziel potwierdzone ustalenia od przypuszczeń i brakujących danych. Uwzględnij szybkie poprawki oraz plan 30 dni.

## Zasady bezpieczeństwa
- Domyślnie tylko odczyt i propozycje; nie zmieniaj WordPressa, DNS, robots.txt, sitemap ani GSC bez wyraźnej zgody właściciela.
- Nie blokuj botów wyszukiwarek ani botów AI bez analizy skutków i osobnej zgody.
- Nie generuj fikcyjnych opinii, lokalizacji, ocen ani wyników wyszukiwania.
- Nie ujawniaj danych dostępowych, tokenów API ani informacji prywatnych.
- Cytuj źródła i podawaj datę kontroli danych zmiennych.
